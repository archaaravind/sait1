🌐 About the Project

SAIT Website is the official digital platform for the Students Association of Information Technology (SAIT) under the Division of Information Technology, School of Engineering, CUSAT.

The website is designed to bring the SAIT community together through a modern, responsive, and interactive experience.

It provides a centralized space for students to discover:

- Technical events and workshops
- Announcements and updates
- Student achievements
- SAIT activities
- Career and placement opportunities
- Alumni connections
- Learning resources
- Student participation records
- People and team information

The interface combines an academic identity with a modern technology-focused visual experience.

🚀 Getting Started

Because this project is built with standard web technologies, it can be run without a complex build system.

1. Clone the repository

git clone https://github.com/archaaravind/sait1.git

2. Enter the project directory

cd sait1

3. Open the website

Open:

index.html

in a modern web browser.

For the best development experience, you can also use a local development server such as VS Code Live Server.

6. Connect students with alumni and industry opportunities.
7. Provide a centralized student resource platform.
8. Create a modern digital representation of the IT student community.
